## Savings and Expense Tracker 3.0.0

- Budget percentage adjustments round exact half-paise results correctly.
- Bulk budget editing preserves saved overrides for inactive categories.
- Android reuses progress calculations when you change the displayed month range.
- Android and Windows save a local recovery copy before replacing the device plan with the complete cloud version during conflict review.

This release includes the Web, Android and Windows builds. Android updates install over the existing app using the same application ID and signing identity.
