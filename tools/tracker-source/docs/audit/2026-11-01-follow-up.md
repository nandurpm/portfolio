## Findings requiring qualification

- The supplied severity summary does not match its individual finding rows.
- A short CSS height can describe a badge or decoration; it is not automatically a touch-target violation.
- Web sign-out already removes the current plan, corrupt recovery copy, last-saved marker and pre-sync backup through clearBrowserData().
- The shared password field offers sign-in and account-creation actions simultaneously; there is no existing sign-up mode to switch autocomplete against. A dedicated registration flow needs separate UX work.
- WebAccess requires online session verification. Local-first native/storage behavior does not establish offline web access; a service worker has not been added.
- Integer-paise storage is a data migration, not a cosmetic fix; existing monetary representations and calculation rules are preserved.
- Public anon keys and build provenance are intentional. CSP inline styles remain necessary for React/chart/motion rendering. Public signup policy must not be inferred from a client call alone.
