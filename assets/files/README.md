# Files

## Purpose

Finalized documents offered as direct public downloads from portfolio pages.

## Contents

- `resume.pdf` — Resume linked from the public resume/about experience.

## Responsibilities

Only finalized, intentionally public downloads belong here. Editable source documents, private records, and temporary exports must remain outside the public asset tree.

## Important Notes

Keep stable filenames when pages link to a document directly. When replacing a document, verify every HTML reference and run `python3 tools/audit_links.py`; the audit confirms path existence but cannot assess PDF content or accessibility.
